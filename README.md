 Калькулятор матриц комплексных чисел

Консольное Java-приложение для выполнения операций над комплексными числами и матрицами произвольного размера. Программа позволяет задавать две матрицы (A и B), выполнять базовые и расширенные матричные операции, а также строить цепочки вычислений благодаря буферу последнего ответа.


Основные возможности

1. Арифметика матриц:
   - Сложение (A + B) и вычитание (A - B)
   - Умножение (A \times B)
   - Матричное деление (A / B = A \times B)
2. Линейная алгебра:
   - Транспонирование матриц
   - Вычисление определителя \det(A)
   - Нахождение обратной матрицы методом Гаусса-Жордана с частичным выбором ведущего элемента по модулю (для численной устойчивости)
3. Удобство использования (UX):
   - Случайная генерация: матрицы можно не только вбивать вручную, но и сгенерировать случайными целыми числами в заданном диапазоне (удобно для быстрого тестирования).
   - Табличный вывод: элементы столбцов динамически выравниваются по ширине, поэтому матрицы любого размера выводятся ровной прямоугольной таблицей без «съезжающих» колонок.
   - Буфер ответа (`Ans`): результат последней операции сохраняется. Его можно посмотреть в любой момент или скопировать обратно в матрицу A или B, чтобы продолжить вычисления.


Структура проекта

- `ComplexNumber.java`  
  Класс комплексного числа вида a + bi. Сделан иммутабельным (значения `re` и `im` неизменяемы). Реализует сложение, вычитание, умножение, деление, вычисление модуля, аккуратный `toString()` (без лишних `.0`) и методы `equals()` / `hashCode()`.

- `ComplexMatrix.java`  
  Класс матрицы комплексных чисел. Содержит реализацию всех матричных операций, проверку совпадения размерностей, алгоритм Гаусса-Жордана, рекурсивный определитель, генератор `random()` и форматированный вывод.

- `Main.java`  
  Точка входа и интерактивное меню. Защищен от некорректного пользовательского ввода (буквы вместо чисел не ломают программу), управляет матрицами A, B и буфером последнего результата.

Пример работы в меню

Калькулятор матриц комплексных чисел 

1. Задать матрицу A
2. Задать матрицу B
3. Показать матрицу A
4. Показать матрицу B
5. Сложить (A + B)
6. Вычесть (A - B)
7. Умножить (A * B)
8. Разделить (A / B)
9. Транспонировать матрицу
10. Вычислить определитель
11. Показать последний результат
12. Скопировать последний результат в A или B

 Пример цепочки вычислений:
1. Задали матрицу A и матрицу B (случайно или вручную).
2. Выбрали пункт 5 (Сложить A + B) — получили результат сложения.
3. Выбрали пункт 12 (Скопировать последний результат) и указали матрицу A.
4. Выбрали пункт 7 (Умножить A * B) — фактически посчитали выражение (A + B) \times B.
